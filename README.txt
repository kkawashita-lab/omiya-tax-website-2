大宮省吾税理士事務所 ホームページ一式

■ 開き方
ZIPを展開し、index.htmlをブラウザで開いてください。

■ ページ
index.html：ホーム
services.html：建設業の税務・顧問
about.html：事務所・代表紹介
fees.html：料金・ご相談の流れ
contact.html：お問い合わせ
column.html：コラム一覧
column-*.html：コラム記事（4本）
assets/：CSS・JavaScript・画像・アイコン

■ GitHub Pagesへ掲載する場合
このフォルダ内のファイルとassetsフォルダを、リポジトリ直下に配置します。
Settings > Pages で、Deploy from a branch、main、/(root)を選択します。
ページと画像の参照は相対パスのため、プロジェクト用URLでも利用できます。

■ 現在の仕様
お問い合わせフォームは入力・内容確認までのデモです。送信・保存は行いません。
料金や詳細住所などの未確定情報は、運用開始前に反映してください。
FVには「代表税理士　大宮 省吾」を追加済みです。
